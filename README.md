# Map Planner

Standalone street-closure and event planning application, starting from DTA's reviewed planning workflows.

**Current status: requirements and extraction plan only. No runnable application or production migration is included.**

Start with [the planning index](docs/planning/README.md) and [the GitHub roadmap](https://github.com/Fayetteville-Downtown-Alliance/map-planner/issues/1). The review captures the existing implementation, requirements to preserve, a scalable standalone design, a source extraction inventory, and delivery/acceptance gates.

The DTA application remains the operational system. No credentials, database exports, contacts, source uploads or production bindings have been copied here.
